# Software & Desktop App Installers - MIJ ERP Digital

Folder ini berisi berkas instalan aplikasi desktop mandiri (*Standalone Native Desktop App*) untuk MIJ ERP Client Portal.

## 📦 Berkas Software:

1. **`MIJ-ERP-Client-Setup.exe`** (Installer Resmi Windows)
   - Jalankan berkas `.exe` ini di Windows untuk menginstal aplikasi desktop mandiri secara otomatis.
   - Aplikasi akan terpasang lengkap dengan shortcut desktop & Start Menu tanpa membutuhkan browser.

2. **`MIJ-ERP-Client-Portable.zip`** (Paket Portable Standalone)
   - Ekstrak berkas `.zip` ini di mana saja, lalu jalankan `MIJ ERP Client Portal.exe` di dalamnya untuk menggunakan aplikasi tanpa proses instalasi.
